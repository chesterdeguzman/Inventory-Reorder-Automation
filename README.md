# Inventory Reorder Automation

Calculates safety stock, reorder points, recommended purchase quantities, and estimated purchase value for 500 SKUs.

## Automation value
The script converts raw demand history into an actionable replenishment file that can be scheduled daily or integrated with an ERP.

## Run
```bash
pip install -r requirements.txt
python src/run_pipeline.py
```
