# Open First

1. Install Python 3.11 or newer.
2. Create and activate a virtual environment.
3. Run `pip install -r requirements.txt`.
4. Run `python src/run_pipeline.py` from the repository root.
5. Review generated files in `outputs/`, `images/`, and `models/`.
6. SQL scripts are in `sql/`; sample CSV data is in `data/`.

All data in this repository is synthetic and safe for a public portfolio.
